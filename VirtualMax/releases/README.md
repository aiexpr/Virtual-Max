# 📦 Релизы и Готовые Сборки (VirtualMax Releases)

В этой папке собраны готовые к использованию скомпилированные программы (без необходимости устанавливать `npm` или `Node.js`):

### 📱 Для смартфонов:
- **`VirtualMax.apk`** *(~65 КБ)* — Готовый установочный файл для Android (5.0 — 15+).

### 💻 Для компьютеров (Windows и Linux):
- **`VirtualMax-1.0.0-Windows-x64.zip`** — Портативная версия для Windows 10/11 (распакуйте и дважды кликните `VirtualMax.exe`).
- **`VirtualMax-1.0.0-Linux.AppImage`** — Автономный исполняемый файл для любых дистрибутивов Linux (Ubuntu, Debian, Fedora, Arch).

---

### ☁️ Как GitHub соберет файлы за вас:
После загрузки репозитория на GitHub в разделе **Actions** автоматически запустятся скрипты `.github/workflows/`, которые соберут свежие установщики `.exe`, `.AppImage`, `.dmg` и `.apk` на облачных серверах GitHub совершенно бесплатно!
