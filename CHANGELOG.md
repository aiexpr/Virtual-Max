# 📝 Changelog

Все значимые изменения VirtualMax документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — на [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Безопасность
- **Ключ подписи APK убран из репозитория** и из процесса сборки по умолчанию:
  `mobile/keystore.jks` больше не трекается git, а пароль `virtualmax123` больше
  не зашит ни в `build.gradle`, ни в `build.sh`. Сборка теперь *fail-closed* —
  падает, если не заданы `KEYSTORE_PASS` / `KEYSTORE_JKS` (CI) вместо тихой
  подписи значениями по умолчанию. Старый ключ следует считать скомпрометированным
  и ротировать (`mobile/tools/rotate_keystore.sh`).
- Уточнены заявления о приватности в README и SECURITY.md: клиент блокирует
  сторонних «свидетелей», но сервер мессенджера по-прежнему видит активность —
  анонимность не гарантируется.

### Добавлено
- **Пользовательские метки (галочки/бейджи):** клиент рисует галочку
  «проверен» и цветные бейджи рядом с именами пользователей по
  централизованному JSON-списку (по ID). Список подгружается по HTTPS-URL
  (по умолчанию — `badges.example.json` в репозитории) и кэшируется локально.
  Работает на Android и Desktop; видимость — только внутри VirtualMax
  (серверная верификация МАКС недоступна по определению клиента-песочницы).

## [1.4.0] — 2026-09-11

### Добавлено
- Новая профессиональная иконка: «щит приватности» + речевой пузырёк + литера
  «V» (PNG, ICO, мастер-SVG, адаптивная иконка Android с round-вариантом).
- Понятный диалог с кнопкой «Открыть настройки», когда ОС отказывает в доступе
  к микрофону/камере.

### Исправлено
- **Звонки:** устранена потеря веб-запросов разрешений, когда мессенджер
  запрашивает микрофон и камеру несколькими запросами подряд (WebView больше
  не отклоняет их молча с ошибкой «нет разрешения»).
- **Звонки (Android):** обработка `RESOURCE_PROTECTED_MEDIA_ID`, из-за отказа
  которому часть прошивок роняла весь `getUserMedia`.
- **Desktop (macOS):** добавлены `NSMicrophoneUsageDescription` /
  `NSCameraUsageDescription` и явный запрос доступа к медиа через
  `systemPreferences` — звонки работают на macOS.
- **Desktop:** разрешения медиа выдаются точечно (audio/video) согласно
  тумблерам; добавлен резервный обработчик `permissionrequest` для `<webview>`
  и поддержка полноэкранного режима видеозвонков.

### Изменено
- Репозиторий приведён к профессиональному виду: `CONTRIBUTING.md`,
  `.editorconfig`, `.gitattributes`, шаблоны Issue/PR, обновлённый README.
- Раздельные request-коды для запросов разрешений микрофона и камеры.

## [1.3.0] — 2026-09-10

### Добавлено
- Существенная оптимизация для слабых телефонов: лёгкий сетевой фильтр без
  regex на каждый запрос, пакетное обновление счётчика блокировок,
  offscreen-рендер, остановка рендерера в фоне и перезапуск после падения
  вместо краша.
- Отправка фото, видео и файлов из чата (галерея, камера, мультивыбор).
- Загрузки через системный `DownloadManager` (с разрешением для Android 9-).
- Runtime-разрешения на микрофон, камеру и уведомления (Android 13+).
- Кнопки «Назад/Вперёд», прогресс загрузки, зум текста, скрытие панелей,
  тёмный дизайн, адаптивная иконка.
- Ghost-режим и блокировка уведомлений применяются на лету; внешние ссылки
  открываются в системном браузере без трекинг-меток.

### Исправлено
- Desktop: облегчённый sandbox, внешние ссылки/попапы в системном браузере,
  сохраняемый зум, горячие клавиши, исправлена вёрстка.
