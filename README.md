## 🧭 Что такое VirtualMax

**VirtualMax** — независимый клиент с открытым исходным кодом для мессенджера
МАКС (`web.max.ru`), работающий по принципу **Zero-Data-Collection**:

> VirtualMax блокирует известные сторонние трекеры и счётчики (VK/Mail.ru,
> Яндекс Метрика, WebVisor, Sentry, AppMetrica), чистит ссылки от меток и
> изолирует сессию в отдельной песочнице.

Клиент — это изолированная песочница: сессия, cookies и кэш мессенджера не
пересекаются с вашим основным браузером, а доступ к датчикам управляется
аппаратными тумблерами.

> ⚠️ **Важное ограничение.** VirtualMax убирает сторонних «свидетелей» (трекеры,
> аналитику, снятие отпечатка устройства), но **не делает вас невидимым для
> самого мессенджера**: сервер МАКС всегда видит, что вы авторизованы и что
> отправляете сообщения. Отключить это на стороне клиента невозможно, и проект
> на это не претендует.

## ✨ Возможности

| Категория | Что делает |
|-----------|------------|
| 🛡️ **Zero-Telemetry** | Блокирует запросы к известным сторонним трекерам `VK / Mail.ru`, **Яндекс Метрике**, **WebVisor**, **Sentry**, **AppMetrica**, внутренние эндпоинты метрик МАКС, защищает IP от утечки через WebRTC, нейтрализует `navigator.sendBeacon()` |
| 🎙️ **Звонки и голосовые** | Полноценные аудио/видеозвонки и голосовые сообщения с корректным запросом разрешений (Android + Desktop) |
| 🎛️ **Тумблеры датчиков** | Микрофон, камера и уведомления включаются/выключаются на уровне приложения |
| 👻 **Режим Невидимки** | Скрывает статус «Печатает…» и онлайн-присутствие |
| 🏷️ **Метки пользователей** | Галочки «проверен» и цветные бейджи рядом с именами по централизованному JSON-списку (по ID) — видны внутри VirtualMax |
| 🔗 **Чистые ссылки** | Вырезает `utm_*`, `yclid`, `fbclid`, `vk_ref` и прочие трекинг-метки из внешних ссылок |
| 🔍 **Масштаб и режим ПК** | Регулировка шрифта 70–160 %, переключение мобильный/десктоп |
| 📎 **Отправка файлов** | Фото, видео и документы из галереи/файлового менеджера, съёмка с камеры (Android) |
| 📥 **Менеджер загрузок** | Сохранение медиа в «Загрузки» через системный `DownloadManager` |
| 🧹 **Экстренная очистка** | Cookies, LocalStorage и кэш — в один клик |
| ⚡ **Оптимизация** | Лёгкий сетевой фильтр без regex на каждый запрос, дорендеринг, остановка рендерера в фоне, восстановление после падения |
| 🎛️ **Удобство** | Кнопки «Назад/Вперёд», индикатор загрузки, скрытие панелей, адаптивная иконка, горячие клавиши (Desktop) |

## 🚀 Быстрый старт

### 📱 Android

Скачайте последний **`VirtualMax.apk`** со страницы
[Releases](https://github.com/aiexpr/Virtual-Max/releases) и установите его
(Android 5.0+). При первом звонке или голосовом сообщении разрешите доступ
к микрофону — после этого звонки работают штатно.

### 💻 Windows / Linux

Скачайте установщик для вашей ОС со страницы
[Releases](https://github.com/aiexpr/Virtual-Max/releases):

| Платформа | Формат |
|-----------|--------|
| Windows 10/11 | `.exe` (установщик) или `.exe` (portable) |
| Linux | `.AppImage`, `.deb` |

## 🔨 Сборка из исходников

### Android (без Gradle, минимальный APK)

Требуется JDK 17 и Android SDK (`platforms;android-34`, `build-tools;34.0.0`):

```bash
cd mobile
./build.sh          # результат: releases/VirtualMax.apk
```

Подпись настраивается переменными `KEYSTORE_PASS` / `KEYSTORE_ALIAS`
(подробнее в [SECURITY.md](SECURITY.md)).

### Desktop (Electron)

```bash
cd desktop
npm ci
npm start             # запуск
npm run build:win     # .exe (установщик) + portable
npm run build:linux   # .AppImage + .deb
```

### CI/CD

При создании тега `v*` GitHub Actions автоматически собирает APK, установщики
Windows и пакеты Linux и публикует их в GitHub Release. Любую сборку можно
запустить вручную из вкладки **Actions**.

## 🧠 Как это работает

```
┌─────────────────────────────────────────────────────────┐
│  WebView (Android) / <webview> (Electron)               │
│        web.max.ru — изолированная сессия                │
├─────────────────────────────────────────────────────────┤
│  1. Сетевой фильтр: блокировка трекеров до сети         │
│  2. JS-песочница: sendBeacon/fetch/XHR/WebSocket хуки,  │
│     анти-фингерпринт (Canvas, Audio, WebGL), Ghost Mode │
│  3. Шлюз разрешений: микрофон/камера/уведомления        │
│  4. Очистка внешних ссылок от трекинг-меток             │
└─────────────────────────────────────────────────────────┘
```

1. **Сетевой фильтр** — перехватывает каждый субресурс страницы и уничтожает
   запросы к известным трекерам (суффиксный hash-матчинг доменов + правила по
   хосту/пути — без regex на каждый запрос).
2. **JS-песочница** — внедряется при загрузке страницы и нейтрализует маяки
   телеметрии, подменяет отпечаток устройства и глушит пакеты «Печатает…».
3. **Шлюз разрешений** — связывает тумблеры приложения с системными
   разрешениями и веб-запросами `getUserMedia`/уведомлений.
4. **Маршрутизация ссылок** — внешние URL открываются в системном браузере
   с вырезанными трекинг-метками.

## 🔐 Приватность и разрешения

- **Микрофон/камера** запрашиваются только тогда, когда мессенджеру они реально
  нужны (звонок, голосовое, фото/видео). Тумблер в настройках — политика
  приложения, системное разрешение — политика ОС; VirtualMax аккуратно связывает
  оба уровня и не теряет веб-запросы при одновременном запросе микрофона и камеры.
- Если система отклонила доступ, приложение показывает диалог с кнопкой
  **«Открыть настройки»** — не нужно вручную искать приложение в параметрах.
- **Уведомления** на Android 13+ запрашиваются отдельно (`POST_NOTIFICATIONS`).
- **Геолокация, сенсоры движения, батарея** — отключены/маскируются принудительно.
