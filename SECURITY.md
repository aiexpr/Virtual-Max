# Политика безопасности (Security Policy)

## 🔒 Принципы конфиденциальности VirtualMax

VirtualMax разработан по принципу **Zero-Data-Collection**:
1. Приложение **само** не собирает и не отправляет пользовательские данные на сторонние серверы.
2. Известные сторонние сетевые трекеры (`VK`, `Mail.ru`, `Яндекс Метрика`, `WebVisor`, `Sentry`, `AppMetrica`) блокируются до выхода в интернет.
3. Доступ к микрофону и камере управляется тумблерами в меню настроек.
4. Внешние ссылки очищаются от трекинг-меток (`utm_*`, `yclid`, `vk_ref`, `fbclid`) перед открытием.

> ⚠️ **Честные ограничения.** VirtualMax — это клиент-обёртка над `web.max.ru`,
> а не прокси и не анонимайзер. Поэтому:
> - **Сервер мессенджера видит вашу активность** (авторизацию, сообщения,
>   статус) — отключить это на стороне клиента невозможно.
> - Собственная телеметрия МАКС может уходить на **first-party домены** и не
>   отделяется от полезного трафика по списку доменов.
> - Полная блокировка «всей телеметрии» и снятие отпечатка гарантируются
>   наилучшими усилиями, но не абсолютно.

## 🐛 Сообщение об уязвимостях

Если вы обнаружили потенциальную уязвимость или не заблокированный эндпоинт телеметрии, пожалуйста, откройте Issue в данном репозитории.

## 🔑 Подпись релизов (CI/CD)

- Ключ подписи (`mobile/keystore.jks`) и его пароль — **секреты** и **не хранятся в git**.
  Сборка работает по принципу *fail-closed*: без ключа и пароля она падает с понятной
  ошибкой, а не подписывает «значениями по умолчанию».
- В CI ключ передаётся через GitHub Secret `KEYSTORE_JKS` (base64), пароль — через
  `KEYSTORE_PASS`, алиас — `KEYSTORE_ALIAS`. Локально положите `mobile/keystore.jks`
  и задайте `KEYSTORE_PASS` переменной окружения (или `-PKEYSTORE_PASS=...` для Gradle).
- Для безопасной генерации нового ключа используйте `mobile/tools/rotate_keystore.sh` —
  он создаёт keystore со случайным паролем и выводит готовые значения
  `KEYSTORE_PASS`, `KEYSTORE_ALIAS` и `KEYSTORE_JKS` для GitHub Secrets.
  ⚠️ Смена ключа меняет подпись APK: уже установленные сборки потребуется удалить
  и переустановить (Android не разрешает обновление с изменённой подписью).
- ⚠️ **Если ключ когда-либо попадал в git-историю — считайте его скомпрометированным**
  и ротируйте. Удаление файла из репозитория не отменяет того, что он уже мог быть
  скопирован: требуется ротация + переписывание истории (`git filter-repo` / BFG).
- CI не отправляет данные на сторонние сервисы; логи публикуются только в GitHub Actions.
